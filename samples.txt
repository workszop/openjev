DECISION SAMPLES - VEGA, BASAL-1.5-MINI, QWEN3
=============================================

How to use: open vega.html, tick the models you want to compare and press "load selected",
then press "load samples.txt" and pick a sample (or paste the STATE block into the State box
and the QUESTIONS block into the Questions box), and press decide (Ctrl+Enter). Each sample
mixes boolean, choice and score questions. Every QUESTIONS block is valid JSON; the State box
also accepts JSON (samples 6 and 12). Samples 7-12 are entirely in Polish: Polish state and
Polish questions, option keys and descriptions.

Your own file: use "open my .txt..." on the page. Write each sample as
  1. a header line that starts with three dashes and a space, then a title
  2. a line with only STATE:, followed by the text to decide (or a JSON object)
  3. a line with only QUESTIONS:, followed by one JSON object of questions
A file with just one STATE: and one QUESTIONS: block (no header) also works.
Samples whose QUESTIONS are not valid JSON are skipped and named on the page.
