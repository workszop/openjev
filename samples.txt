VEGA vs QWEN3 - SAMPLE DECISIONS
================================

How to use: open vega.html, load Vega (and Qwen3 0.6B to compare), then for each sample
paste the STATE block into the State box and the QUESTIONS block into the Questions box
and press decide (Ctrl+Enter). Each sample mixes boolean, choice and score questions.
Every QUESTIONS block is valid JSON; the State box also accepts JSON (sample 6).

--- 1. Hotel review ------------------------------------------------
A mixed review: tests score vs choice vs boolean on the same text.

STATE:
Stayed three nights in March. The room was spotless and the bed was great, and the staff at reception went out of their way to find us a late checkout. Breakfast was the weak point: the same cold eggs every day and the coffee machine was broken twice. The location near the old town is perfect, but the street noise until 2 am made it hard to sleep with the window open. For the price I would probably come back, but I would ask for a room at the back.

QUESTIONS:
{
  "rating": {
    "type": "score",
    "instructions": "How positive is this review overall?",
    "criteria": [
      "very negative",
      "negative",
      "mixed",
      "positive",
      "very positive"
    ]
  },
  "main_complaint": {
    "type": "choice",
    "instructions": "What does the guest complain about most?",
    "criteria": {
      "cleanliness": "dirty rooms or bathrooms",
      "food": "breakfast, restaurant, drinks",
      "noise": "street, neighbours, building noise",
      "staff": "rude or unhelpful staff",
      "price": "poor value for money"
    }
  },
  "would_return": {
    "type": "boolean",
    "instructions": "Does the guest say they would stay here again?",
    "criteria": null
  }
}
